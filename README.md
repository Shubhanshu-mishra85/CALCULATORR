# 🌸 Pink Neon Calculator UI

A stylish futuristic calculator UI made using **HTML** and **CSS** only.
This project features a pink cyberpunk background, glowing neon effects, smooth hover animations, and a modern glassmorphism design.

---

## 🚀 Features

* 💖 Pink Neon Theme
* ✨ Glassmorphism UI
* 🌌 Cyberpunk Background
* 🔥 Glow Effects
* 🎨 Hover Color Animation
* 📱 Fully Responsive Design
* ⚡ Pure HTML & CSS
* 🚫 No JavaScript Used

---

## 🛠️ Technologies Used

* HTML5
* CSS3
